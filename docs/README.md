## 왜 지우지 않고 남기는가

**결론만 적으면 다음 사람이 같은 함정에 빠진다.**

이 프로젝트에서 같은 종류의 버그가 여덟 번에 걸쳐 다른 얼굴로 나타났다. "제" 표기 → 전국 단위 목록 → 인코딩 손상 → 가운뎃점. 매번 "이제 다 고쳤다"고 판단했지만 아니었다.

폐기한 군집 모델도 마찬가지다. 지우면 "처음부터 k=6이었다"가 되어, 왜 그 방식을 택했는지 설명할 수 없어진다.

> 코드는 다시 짤 수 있지만 **왜 그렇게 했는지는 기록하지 않으면 사라진다.**
