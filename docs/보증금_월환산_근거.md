# 보증금 월환산 근거

`web/service.py` 의 `DEPOSIT_RATE_BY_REGION` · `_deposit_monthly()` 가 무엇을
왜 그렇게 계산하는지 남긴다.

## 문제

보증금과 월세는 단위가 다르다. 보증금은 한 번 맡기는 목돈이고 월세는 매달
나가는 돈이다. 그대로 더할 수 없는데, 주거비를 한 숫자로 보여주려면 합쳐야
한다. 보증금 1,000만원에 월세 75만원인 집과 보증금 1억에 월세 40만원인 집을
비교할 방법이 필요했다.

## 방법

전월세전환율로 보증금을 월 단위로 환산해 월세에 더한다.

```
월환산액 = 보증금 × 전월세전환율 / 12
표면주거비 = 월세 + 월환산액
```

## 적용 전환율

권역별 중앙값을 쓴다. 괄호는 산출에 쓰인 거래 수다.

| 권역 | 전환율 | 거래 수 |
|---|---|---|
| 도심권 | 6.10% | 30,360 |
| 동남권 | 5.39% | 103,894 |
| 동북권 | 6.20% | 161,402 |
| 서남권 | 5.90% | 204,026 |
| 서북권 | 6.20% | 78,079 |
| **권역 미상** | **5.90%** | 전체 중앙값 |

### 왜 권역까지만 나누는가

전환율은 원래 주택유형(아파트·연립다세대·단독다가구)에 따라서도 갈린다.
그런데 **서비스가 주택유형을 입력받지 않는다.** 입력 항목을 하나 더 늘리는
대신 권역 중앙값으로 계산하고, 유형에 따라 달라질 수 있다는 점을 화면에서
밝히는 쪽을 택했다.

권역을 알 수 없는 경우(조회 실패, 서울 밖)에는 전체 중앙값 5.9% 로 물러선다.

## 검산

동남권, 보증금 1,000만원, 월세 75만원인 경우.

```
1,000만 × 0.0539 / 12 = 44,917원
표면주거비 = 75만 + 4.5만 = 79.5만원
```

## 바뀐 이력

초기에는 전 지역에 3.48% 하나를 썼다. 권역별 값으로 교체하면서 같은 입력의
표면주거비가 **77.9만원에서 79.5만원으로 1.6만원 올랐다.**

수치가 바뀐 것이지 계산이 틀렸던 것은 아니다. 다만 전 지역 단일값은
"서울 어디든 보증금의 가치가 같다"는 가정이었고, 권역별 거래 수를 보면
그 가정이 성립하지 않는다. 동북권(6.20%)과 동남권(5.39%)의 차이는
같은 보증금 1억에 대해 월 6.8만원 차이가 된다.

## 한계

- 권역 중앙값이라 개별 계약의 조건(주택유형, 층, 연식)은 반영되지 않는다.
- 전환율은 시장 상황에 따라 움직인다. 산출 시점 이후의 변동은 반영되지 않는다.
- 실제 계약에서 적용되는 전환율은 임대인과의 협의로 정해지며, 통계값과
  다를 수 있다.
